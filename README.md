# Cleanshop API
Cleanshop är ett web API som är byggt med ASP:NET core & Clean Architecture. 
#Tekniker - ASP.NET Core Web API
-clean architecture 
-CQRS
-MediatR 
-Entity Framework core
-SQL server LocalDB 
-Repository Pattern
-Swagger

#Projektstruktur 
uppdeöad i 4 delar: 
-Cleanshop. API
-Cleanshop.Application
-Cleanshop.Domain
Cleanshop.infrastructure

Funktioner
-skapa prdukt 
-hämta alla produkter
-hämta produkt med Id
-Uppdatera produkt 
-Radera produkt
